# 更換映像檔

在「設定」頁更換映像檔，排程工作也會跟著更換。執行 `kubectl apply` 後，3 個服務會重新啟動。

見[安裝說明](https://example.com/install)。網域名稱可以在網域頁修改。

這台伺服器是 Docker Hub 的鏡像站，國內下載比較快。

權杖被盜用時，立刻撤銷。節點恢復或副本移走之前，上面的服務都會停擺。

這個設定——保留期限——很少需要修改。正在儲存…
